# SHORT 危険日ゲート — オフライン候補メモ

記録日: 2026-06-19
ステータス: **オフライン候補のみ（本番未採用・本番gate化していない）**

## 候補ゲート

```
BLOCK if (btc_ema_slope_1h の日次平均 > -0.002)
      OR (btc_slope_chg1 の日次平均 > +0.0002)
```

- `btc_slope_chg1` = `slope_1h(t) - slope_1h(t-1h)`（slopeの1時間変化量、下落減速の検知用）
- これは **本番通知に効かせるゲートではない**。次回 EntryRecord で前向き観察する第一候補としての記録。

## 検証条件

- データ: BTC OHLCV（15m/1h）からバックフィルした SHORT DONE 43,170行（5/1〜6/19）
- 7特徴量はすべて bot 記録値と corr ≥ 0.92 で突合済み。slope_1h / ret4h は grid再計算 vs validated backfill で corr = 1.000
- train/test 時系列分割: train 5/1〜6/2、test（OOS）6/3〜6/19
- 損益分岐 WR = 42.9%（medTP 0.95% / medSL 0.72% / fee 0.15%）、pnl_net = PnL_Pct − 0.15

## ロバスト性チェック（5項目）

1. **slope_chg1 閾値スイープ**: +0.0001〜+0.0002 では安定して改善（WR 51.6% / PnL +0.126）。**+0.00025 以上で基準に戻る（崖）**。6/15・6/17 の実値が chg1≈+0.0002 に密集しているため境界依存リスクあり
2. **slope 閾値スイープ**: -0.0015〜-0.0030 で崩れない（厳格化 -0.0025 ではさらに改善するが PASS n=5 に減少）
3. **勝ち日 6/3-6/6**: 4日とも PASS 維持（消しすぎていない）
4. **10/20/30日比較**: 全 window で候補が基準を上回る（差 +0.063〜+0.083）
5. **BLOCK側の負け日集中**: BLOCK 9日中 7日が負け日（WR<42.9%）= 78%。誤ブロック（勝ち日）は 6/11(+0.013)・6/14(+0.088) の僅少PnL 2日のみ
