# SHORT 危険日ゲート — オフライン候補メモ

記録日: 2026-06-19
ステータス: **オフライン候補のみ（本番未採用・本番gate化していない）**

## 候補ゲート

```
BLOCK if (btc_ema_slope_1h の日次平均 > -0.002)
      OR (btc_slope_chg1 の日次平均 > +0.0002)
```

- `btc_slope_chg1` = `slope_1h(t) - slope_1h(t-1h)`（slopeの1時間変化量、下落減速の検知用）
- これは **本番通知に効かせるゲートではない**。次回 EntryRecord で前向き観察する第一候補としての記録。

## 検証条件

- データ: BTC OHLCV（15m/1h）からバックフィルした SHORT DONE 43,170行（5/1〜6/19）
- 7特徴量はすべて bot 記録値と corr ≥ 0.92 で突合済み。slope_1h / ret4h は grid再計算 vs validated backfill で corr = 1.000
- train/test 時系列分割: train 5/1〜6/2、test（OOS）6/3〜6/19
- 損益分岐 WR = 42.9%（medTP 0.95% / medSL 0.72% / fee 0.15%）、pnl_net = PnL_Pct − 0.15

## ロバスト性チェック（5項目）

1. **slope_chg1 閾値スイープ**: +0.0001〜+0.0002 では安定して改善（WR 51.6% / PnL +0.126）。**+0.00025 以上で基準に戻る（崖）**。6/15・6/17 の実値が chg1≈+0.0002 に密集しているため境界依存リスクあり
2. **slope 閾値スイープ**: -0.0015〜-0.0030 で崩れない（厳格化 -0.0025 ではさらに改善するが PASS n=5 に減少）
3. **勝ち日 6/3-6/6**: 4日とも PASS 維持（消しすぎていない）
4. **10/20/30日比較**: 全 window で候補が基準を上回る（差 +0.063〜+0.083）
5. **BLOCK側の負け日集中**: BLOCK 9日中 7日が負け日（WR<42.9%）= 78%。誤ブロック（勝ち日）は 6/11(+0.013)・6/14(+0.088) の僅少PnL 2日のみ

## 【2026-06-19 追記】6/19型（下落加速・低WR日）の分離不能 検死メモ

**目的：** 同じ6/19型探索を毎回繰り返さないための記録。これは「待ち」ではなく過学習候補の固定。

**結論：6/19型は現時点の検証済み7特徴量の単純OR追加では分離不能。**

### なぜ分離できないか（構造）

6/19（負け WR27.1%）と 6/4（勝ち WR63.6%）の特徴量はほぼ同じで、特に rsi15m が同水準：

| 日 | WR | slope | ret4h | vol1h | rsi15m | rebound |
|---|---|---|---|---|---|---|
| 6/4（勝ち） | 63.6% | -0.0061 | -0.0163 | 0.0045 | 37.3 | 0.0060 |
| 6/19（負け） | 27.1% | -0.0040 | -0.0092 | 0.0021 | 37.6 | 0.0033 |

rsi はほぼ同じ（37.3 vs 37.6）なのに正反対の結果。違いは「下落の深さ」と「ボラ」のみ。6/19は浅い・低ボラの下落、6/4は深い・高ボラの下落。**反転系（rsi/rebound/green）では両者を区別できない。**

### 棄却した候補（すべて過学習 or 勝ち日破壊）

- **`vol1h < 0.0025`**: test では WR61.9%/+0.455 と見栄え良く 6/19,6/7,6/8,6/15 を全BLOCKするが、**train では33日中33日を全ブロック（PASS=0）**。全期間50日中44日(88%)が該当。train相関 corr(WR,vol)=+0.014（無相関）。汎化根拠なし。test で効くのは「test の危険日がたまたま低ボラだった」偶然。→ **棄却**
- **`rsi15m < 38/40`**: 6/19を捕まえるが **train符号と逆**（train: corr(WR,rsi)=-0.53 で高rsi=危険、候補は低rsi=危険）。かつ勝ち日を1〜2日消す。→ **棄却**
- **`rebound > 0.004〜0.005`**: 勝ち日6/3-6/6を4日消す。→ **棄却**
- **`rsi15m > th` / `green==1` / `vol1h < 0.0020`**: 6/19を捕まえられない（✗）。

### 固定する判断

- 6/19型は**既知の残課題**として記録。現7特徴量では捕捉しない
- **6/19型のサンプルが追加で出るまで、新条件を6/19専用に作らない**（OOS 1日に合わせるのは教科書的過学習）
- 6/19型を捕まえるには「下落の深さに対する相対ボラ」等の新しい条件特徴量が要るが、サンプル不足のため設計しない
- 次回 EntryRecord の `Short_Danger_Gate_Shadow` 前向き記録で、同型の低WR日（slope深い・slope_chg1負・低ボラ・PASS判定）が追加されるか確認する。2〜3日揃ってから初めて特徴量設計を検討する
